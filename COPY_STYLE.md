# CodeGym Copy Style

- Use **Title Case** for headings, topic and path titles, navigation, buttons, field labels, and menu options. Capitalize major words; lowercase articles, coordinating conjunctions, and short prepositions in the middle of a title.
- Use **sentence case** for descriptions, explanations, hints, feedback, and status messages. Complete sentences end with punctuation.
- Keep short eyebrow labels in the existing uppercase presentation.
- Preserve brand and technical names: CodeGym, JavaScript, Node.js, HTML, KQL, Swift, Kotlin, Go, R, C++, VHDL, PostgreSQL, Kubernetes, Ansible, and Podman.
- Preserve the exact spelling and case of code identifiers, API names, commands, arguments, configuration keys, code examples, accepted answers, and answer choices. A title mentioning `std::move`, `for_each`, or `finally` retains that spelling.
- Use American English: behavior, initialize, and analyze. Keep technical distinctions such as read-only versus immutable intact.
- Use the Oxford comma in prose lists.

This pass standardizes all 575 question titles, 92 concept headings, seven path names, and interface headings and labels. The spelling review treats technical terms as glossary entries rather than blindly replacing dictionary exceptions.
