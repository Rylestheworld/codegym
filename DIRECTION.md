# CodeGym Direction

[KC7](https://kc7cyber.com/) inspired paths that organize a learner’s journey and cases that give practice a purpose. CodeGym retains its own name, content, palette, and three symbols.

## Current Structure

- Learn: 23 introductions and 115 tier lessons with explanations, examples, tasks, and notes.
- Practice: 575 quick-rep questions, 14 JavaScript/Python written exercises, topic placement, and delayed retention checks.
- Training Grounds: seven paths and three connected missions spanning deployment debugging, login investigation, and assembly reconstruction.
- Content: stable question IDs, reviewed aliases, official references, and local ambiguity reports.
- Progress: version-2 local storage and JSON backups, with migration of prior practice history.

Everything remains static and local. Paths reuse topic progress. Written functions execute in time-limited disposable browser workers; the server serves files only. Mission evidence is fictional, the KQL evaluator is deliberately bounded, and debriefs are compared with a guide by the learner.

## Extension Points

Add broader written tasks and more independent transfer variants when the existing learning flow proves useful. Additional runtimes should follow the same disposable-worker model where appropriate. More missions can reuse supplied evidence, guided steps, linked lessons, and a reasoned debrief. Curriculum tiers express relative difficulty within this compact bank; they do not certify professional expertise. The practical spacing policy can be adjusted as learner feedback reveals what supports retention.

Accounts, live cloud integration, leaderboards, and shared execution infrastructure remain future product choices.
